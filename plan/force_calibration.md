# 力标定计划：称重传感器 + ESP32-S3

状态：**规划中，硬件待采购**（2026-10-06）

## 1. 目标

当前上位机显示的是 ADC 增量（0–255），不是力。本计划要做到：

1. **总力（N）**：整片传感器受到的法向合力。这是主要目标，预期误差 ±10–20%。
2. **力分布（N / 点）**：每个传感点的力，和总力保持一致。误差比总力大，用来看分布。
3. 热力图和 MuJoCo 上位机加 `--calibration` 参数，直接显示牛顿值和色标。

## 2. 原理

把触觉传感器贴在一台自制"电子秤"的托板上。不管按在哪里，按下去的力都会全部传到下面的称重传感器上。电脑同时读两路串口，用同一个时钟打时间戳，把"触觉读数"和"真实总力"一一配对。

```
        手 / 压头
           ▼
  ┌──────────────────┐   触觉传感器 12×32 ── FPC ── 读出板 + Nano ──USB(ttyUSB0)──┐
  ├──────────────────┤   上托板（3–5 mm 铝板）                                    │
  │   ▬▬▬▬▬▬▬▬▬▬▬    │   单点式称重传感器 5 kg                                    ├─► 电脑
  ├──────────────────┤   底板                                                    │
  └──────────────────┘        └── HX711 ── ESP32-S3 ──USB(ttyACM0)─────────────────┘
```

**为什么用独立的测力板：** 触觉 Nano 在以 2 Mbaud 连续发送二进制帧，时序很紧。把 HX711 也接在它上面，扫描会变慢，数据流也会被打乱。所以两块板各用一根 USB，由电脑对齐时间。

## 4. 接线

### HX711 ↔ ESP32-S3

**ESP32-S3 是 3.3 V，引脚不耐 5 V。**

| HX711 | ESP32-S3 | 说明 |
| --- | --- | --- |
| VCC | **3V3** | 只有一个 VCC 脚的小板必须接 3.3V，接 5V 的话 DT 会输出 5V |
| VDD（如果有） | 3V3 | 有 VCC / VDD 两个脚的板子：VCC 可以接 5V，VDD 接 3.3V |
| GND | GND | — |
| DT | GPIO4 | — |
| SCK | GPIO5 | — |

不要用的引脚：

- GPIO0、3、45、46：启动模式引脚
- GPIO19、20：原生 USB
- GPIO35–37：8 线 PSRAM 型号占用
- GPIO43、44：串口 0

### 称重传感器 ↔ HX711

| 线色（常见，以商家说明为准） | HX711 |
| --- | --- |
| 红 | E+ |
| 黑 | E− |
| 绿 | A+ |
| 白 | A− |

按压后读数变小，就把 A+ 和 A− 对调。

### USB

两块板都**直接插电脑本身的 USB 口**，不要经过不带供电的 Hub。2026-10-06 触觉 Nano 插在 USB 2.0 Hub 上，反复出现 `error -32` 和断开，最后系统认不出设备。

## 5. 机械组装

1. 底板 → 垫块 → 称重传感器固定端 → 称重传感器 → 另一端 → 垫块 → 上托板。
2. 触觉传感器平贴在上托板中间。
3. FPC 排线留出松弛的余量，固定在底板或桌面上，**不能绷着拉托板**。排线的拉力会被算进称重读数里。
4. 去皮清零时，排线要处于实际使用时的状态。

**时间对齐：** HX711 以 80 Hz 采样，触觉约 125 fps。把力的数据按触觉帧的时间戳插值；HX711 内部滤波带来的延迟，用两路信号的互相关估计出一个固定偏移，再补偿掉。按压时慢一点（每次 5–10 秒），对齐误差就可以忽略。

## 7. 采集流程

1. **称重传感器标定**：空载去皮，放 500 g 求换算系数，再用 1 kg 验证，误差应小于 1%。
2. **预热**：两块板通电 5 分钟。触觉在不受力时做基线校准，称重去皮。固件要和以后实际使用的版本一致。
3. **整面加压（方法 C）**：硅胶垫 + 平板盖住整片传感器，从 0 加到大约 30 N 再卸载，做 3 次。
4. **小压头逐点压（方法 A）**：用 Ø5 mm 压头，在整片传感器上均匀取 20–40 个位置，每处从 0 加到大约 10 N 再卸载。
5. **多种压法（方法 B 用）**：Ø10、Ø20 mm 压头，按中心、四角、边缘和随机位置，每次 5–10 秒慢慢加载、卸载，重复 5 次以上。
6. **留出验证集**：留一个压头和几个没用过的位置不参与拟合，最后用来检验精度。

每段录制都打标签：压头、位置、第几次。

## 8. 从总力推到每个点的力

一个称重传感器每帧只给出一个总力 F，阵列有 384 个点。只看一帧解不出来，要靠下面的模型加大量不同的按压。

### 模型

```
fᵢ = kᵢ · g(rᵢ)          第 i 个点的力：共用曲线 g × 该点增益 kᵢ
F  = Σᵢ kᵢ · g(rᵢ)       所有点之和 = 称重读数
```

- rᵢ：第 i 个点平滑后的增量（扣掉基线）
- g：所有点共用的"读数 → 力"单调曲线，用分段线性基函数表示：g(r) = Σⱼ wⱼ φⱼ(r)
- kᵢ：每个点的灵敏度修正，接近 1

### 求解

1. **方法 C** 给出每个点 kᵢ 的初始值：整面加压时近似认为压强均匀，fᵢ ≈ F × 单点面积 / 接触面积。
2. 固定 kᵢ，F = Σⱼ wⱼ · Σᵢ kᵢ φⱼ(rᵢ) 对 w 是线性的。几万帧数据，用最小二乘求 w，并约束 wⱼ ≥ 0，保证曲线单调。
3. 固定 g，求 kᵢ，也是线性最小二乘。正则项：‖k − 1‖² + λ·Σ(相邻点 kᵢ 之差)²。
4. 第 2、3 步交替迭代，直到收敛。
5. **方法 A** 的单点数据用来检查：曲线 g 在单点受压时是否也成立。

**能标定的范围：** 只有被压到过的点，它的 kᵢ 才能被确定。所以采集时要把整个表面都压到。

### 验证和精度预期

| 项目 | 怎么检验 | 预期 |
| --- | --- | --- |
| 总力 | 验证集上 Σfᵢ 和称重读数比较：RMSE、相对误差，加载和卸载分开统计 | ±10–20% |
| 滞回 | 加载曲线和卸载曲线的差 | 输出一个统一的平均模型，同时报告加载 / 卸载各自的误差 |
| 力分布 | 只能间接验证（4 角称重测压力中心，可选） | 只看分布，不作为精确读数 |

## 9. 已知局限

- 压阻式传感器有非线性、滞回、蠕变，还会随温度漂移。
- 读数和接触面积有关：标定用的压头和实际接触物越接近越准。
- 固件只输出 8 位数据，并且用的是高速 ADC。换固件、重新贴传感器、改 offset 都要重新标定。
- 输出的是**法向力**。剪切力（侧向推）测不出来。
